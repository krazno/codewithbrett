# codewithbrett.com

Ursuline Academy (Dedham, MA) class site.

## Routes

| URL | Page |
|-----|------|
| `/` | Ursuline home — links to all class materials |
| `/ursuline-ai/` | Student lesson (*AI, the Brain, and Serviam*) |
| `/artifacts/` | Student handouts and faculty files |

## Local

```bash
npm install
./serve.sh
```

- http://127.0.0.1:3000/
- http://127.0.0.1:3000/ursuline-ai/

Production: [www.codewithbrett.com](https://www.codewithbrett.com/)
